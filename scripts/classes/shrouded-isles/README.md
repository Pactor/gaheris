# Shrouded Isles classes

Empty for now. Bonedancer, Animist and Valewalker are flagged broken or
missing in `docs/expansion-class-audit.md` and have not been worked on. This
folder is where that goes.

Shrouded Isles (November 2002) added six classes -- Necromancer and Reaver in
Albion, Savage and Bonedancer in Midgard, Valewalker and Animist in Hibernia
-- along with the Flexible, Scythe and Hand-to-Hand weapon lines.

They are a different six from the Catacombs classes next door, which is an
easy conflation to make: Catacombs added five, in December 2004, and the
Mauler came later still.
