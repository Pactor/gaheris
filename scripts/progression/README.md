# progression/

Endgame progression the core ships the apparatus for and none of the content.
Not tied to one expansion, and not specific to this server.

| File | |
|---|---|
| `ChampionLevels.cs` | Where champion experience comes from. OpenDAoC carries the field and never fills it |
| `MasterLevels.cs` | Master Levels made reachable -- the whole apparatus ships with no way to earn one |
| `RealmRanks.cs` | Realm rank 15, which live added above 14 |

Settings live under the `progression` category: `cl_xp_per_level`,
`ml_xp_per_level`, `max_realm_level`.

`GaherisArbiter` in `MasterLevels.cs` keeps its name -- three `mob` rows name
it in `ClassType`.
